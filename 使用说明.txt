河南大学 henu-student 校园网自动登录助手
========================================

版本：2.5（网页控制台与托盘状态面板）
支持：移动、联通、电信，以及校园资源账号。

安装：
1. 双击“安装校园网自动登录.cmd”。
2. 输入自己的校园网账号和密码。
3. 选择移动、联通或电信，点击“安装并开始守护”。

2.5 新增：
- 网页控制台：双击桌面“校园网控制台”（或托盘菜单“打开网页控制台”），在浏览器里填写账号、密码、运营商，点“保存并登录”即可立即登录；也可只修改运营商或密码。
  · 控制台只在本机 127.0.0.1 运行，不对局域网开放；每次启动生成随机令牌，其他网站无法读取或操作它。
  · 密码仍由当前 Windows 账户 DPAPI 加密保存；修改运营商时密码可留空，更换账号时需重新输入密码。
  · “保存并登录”也会先检查网络，已经联网就不会重复认证。
- 右下角托盘状态：托盘里的 Wi-Fi 图标按状态变色（绿=已联网，蓝=处理中，橙=稍后重试，红=需要处理，灰=检测中/未发现热点）。
  · 单击图标弹出右下角状态面板：显示当前状态、账号与运营商、上次检测时间、上次失败原因，可一键“立即登录”“网页控制台”“查看日志”。
  · 登录成功或失败时会弹出系统通知（自动失败的提醒至多每 10 分钟一次）。
  · 图标可能被 Windows 收进任务栏的“^”里；可拖到任务栏上常驻显示。
- 打开控制台.cmd：如果没有桌面快捷方式，也可以双击“打开校园网控制台.cmd”。

安装后：
- 进入 Windows 桌面后会询问“今天在学校吗？”。
- 选择“是”后会显示连接状态；需要认证时会打开专用 Edge 窗口，自动填写、选择运营商并点击登录。
- 状态面板位于屏幕右下角，点别处会自动收起到托盘。正常上网时约每 10 秒检查一轮，不弹出认证页，也不切换你正在使用的网络。
- 常规联网检测在同一进程的后台线程内运行，不再每轮启动 PowerShell 子进程，减少命令窗口闪现和启动开销。界面不会等待联网请求完成才响应。
- 只有确认断网后的恢复任务才启动独立进程，并禁止创建控制台窗口；需要网页登录时仍会显示专用 Edge 窗口。
- 不控制远控软件、显卡、屏幕或锁屏设置；这项优化不能保证解决其他原因导致的远控黑屏。
- 每轮同时验证百度、腾讯、网易三个国内站点的 HTTPS 内容；任何一个通过即认为有互联网，不会因某一个网址超时就重新登录。不会将认证页的 HTTP 200 当成联网成功。
- 所有验证连续至少 3 轮失败且持续至少 15 秒，才尝试恢复。打开网页前、提交账号前再次检查，已经恢复则取消认证。
- 点击“立即检查并恢复”仍然先检查互联网，不会强制重复登录。旧版命令行 ForceLogin 参数也不再绕过检查。
- 认证尝试有 120 秒起步、最多 300 秒的间隔；间隔期间继续检测网络，避免频繁弹窗。恢复时间取决于 Wi-Fi、网页及运营商响应，不保证 20 秒内恢复。
- 选择“否”后，本次登录期间不会自动连接校园网。
- 安装程序会把 henu-student 设为 Windows 手动连接模式，避免选“否”后系统自行连接。
- 只有检测到 henu-student 在附近时才尝试连接，不会影响在家或其他地点使用 Wi-Fi。
- 密码使用当前 Windows 账户加密保存，不能复制到另一台电脑直接解密。
- 网页自动登录按控件名称识别，不依赖屏幕坐标，不会因为窗口位置或分辨率变化而点错。
- 需要 Windows 自带的 Microsoft Edge；认证成功后专用窗口会自动关闭，失败时会保留页面供检查。
- 正常关机或注销时守护程序会允许 Windows 关闭；点状态面板以外的地方或按 Alt+F4 只会收起到托盘，退出请用托盘右键菜单“退出本次守护”。
- 状态和配置文件先写临时文件再原子替换；日志超过 1 MB 后保留一份旧日志。

如果开机时选了“否”，后来又到了学校：
- 双击“启动本次校园网自动连接.cmd”，再选择“是”。

修改账号、密码或运营商：
- 打开网页控制台修改后点“仅保存”或“保存并登录”；也可以重新运行安装程序覆盖原配置。

卸载：
- 双击“卸载校园网自动登录.cmd”。
- 卸载也会删除本工具创建的桌面“校园网控制台”快捷方式。
- 卸载会关闭守护、登录子进程和认证专用 Edge；失败时显示具体残留项。
- henu-student Wi-Fi 配置会保留并继续使用手动连接模式，卸载程序不会自动删除它。

故障日志：
- %LOCALAPPDATA%\HenuAutoLogin\auto-login.log

注意：
- 首次使用前，Windows 中需已有名为 henu-student 的 Wi-Fi 配置（正常手动连接过一次即可）。
- 如果学校以后更换认证系统，可能需要更新脚本。
- 联网验证不是对所有网站的保证：某个应用或网站单独打不开，而其他外网正常时，不会因此重复认证。
- 使用 Windows 系统代理正常上网时也视为在线。三个检测站点均被防火墙或代理拦截时仍可能误判，可退出守护并反馈日志。
- 学校当前认证入口是 http://172.29.35.36:6060，不支持 HTTPS。密码在本机由 DPAPI 加密保存，但提交给该页面时的网络传输不是加密连接。只应在可信的校园网中使用；如学校提供 HTTPS 入口，应优先更换。
- 认证程序会校验固定来源和页面控件，但这无法消除 HTTP 在开放 Wi-Fi 上被监听或篡改的固有风险。
- 需要认证时，程序会尝试从校园网重定向中读取当前区域的 wlanacname；只接受固定校园认证来源和合法参数。未取得有效值时才回退到 HD-SuShe-ME60。
